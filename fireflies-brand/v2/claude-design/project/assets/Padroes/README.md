# Padrões

Quatro padrões sem emenda, cada um em `-claro` (Anil sobre Cal Virgem; lanterna com contorno Anil) e `-escuro` (Cal e Céu sobre Anil; lanterna Âmbar). Uma lanterna por tile.

- `campo-estrelas` (tile 720): capas, verso de cartão, fundos de slide.
- `reticula-celeste` (tile 480): páginas, mapas, área de gráfico. No site, atrás da metade direita dos heros em Anil, com opacidade de 0,38.
- `constelacao-continua` (tile 720): redes sociais, divisórias, envelopes.
- `matriz-pontos` (tile 600): painel mensal, tabelas, fundo de dados.
- Um padrão por composição, nunca atrás de texto corrido.
