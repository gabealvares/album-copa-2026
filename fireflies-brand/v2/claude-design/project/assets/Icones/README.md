# Ícones

79 ícones de linha em grid 24, traço 1,5, pontas e junções redondas, tinta Anil `#17183A`, versão para fundo claro. A lanterna (`class="lit"`) é um círculo Âmbar `#F2B544` com contorno Anil: **no máximo uma lanterna acesa por peça**.

- Mínimo de 20px; os densos (fiscal, dre, condominios, turma) só a partir de 20px. Não altere a espessura do traço.
- Categorias: serviços (auditoria, contabil, fiscal, financeira, processos, sindicancia, condominios, academy); contabilidade e finanças; condomínio; processos e tecnologia; pessoas e comunicação; Academy; interface (setas, check, fechar, mais, menos, busca, menu, download, link, info, alerta, calendario).
- Setas têm cauda pontilhada (trajetória). Itens de interface ficam limpos.
