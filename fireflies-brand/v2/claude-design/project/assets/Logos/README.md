# Logos

Sistema "Órbita do vagalume". Arquivos `fireflies_{versão}_{cor}.svg`; use exatamente estes arquivos, sem redesenhar.

- `fireflies_horizontal_digital.svg`: **principal** em tela (site, documentos, e-mail), sobre Branco ou Cal. Mínimo de 240px de largura.
- `fireflies_horizontal_digital-negativo.svg`: a mesma sobre Anil ou foto com véu Anil.
- `fireflies_horizontal_chapado.svg` / `…_chapado-negativo.svg`: 2 cores (Anil + Vermelhão; Cal + Âmbar no negativo), sem degradê, para impressão.
- `fireflies_horizontal_mono-anil.svg`: 1 cor, tinta Anil `#17183A`, no claro. `fireflies_horizontal_mono-branco.svg`: 1 cor, tinta Branco, no escuro.
- `fireflies_vertical_digital.svg` / `…_digital-negativo.svg`: capas, redes e peças quadradas.
- `fireflies_simbolo_digital.svg` / `…_digital-negativo.svg` / `…_mono-anil.svg`: F em órbita, a partir de 40px (avatar, selo, rodapé de slide).
- `fireflies_simbolo-pequeno_digital.svg` / `…_digital-negativo.svg`: de 24 a 39px.
- `fireflies_favicon_digital.svg` / `…_digital-negativo.svg`: favicon, o vagalume com rastro curto, a partir de 32px. `fireflies_favicon-16_digital.svg`: o mesmo desenhado para 16–31px. O favicon nunca é o F.
- `fireflies_wordmark_digital.svg` / `…_digital-negativo.svg`: só o nome, quando a órbita já aparece na peça.
- `fireflies_condominios-horizontal_digital.svg`: linha de auditoria de condomínios. `fireflies_academy-horizontal_digital.svg`: Fireflies Academy.
