# Ornamentos

21 peças de carta celeste em tinta Anil (linhas secundárias em Pedra-Sabão), textos convertidos em curvas.

- Retículas: `reticula-planisferio`, `reticula-plana`. Medida: `regua-graduada`, `limbo-astrolabio`, `escala-grafica`.
- Orientação: `rosa-de-pontos`, `marca-posicao`, `etiqueta-coordenada`. Selos: `selo-graduado` (centro livre para o símbolo), `selo-graduado-texto`.
- Vagalume: `trilha-photinus` (os pontos crescem na subida e terminam na lanterna). Legenda: `numerais-magnitude`, `linha-de-chamada`.
- Listas: `marcador-estrela`, `marcador-estrela-acesa`, `marcador-ponto`. Divisores e molduras: `divisor-pontilhado`, `divisor-constelacao`, `cantoneira-graduada`, `moldura-carta`, `cartela`.
- Ornamento é apoio: um ou dois por peça, nunca competindo com o título.
