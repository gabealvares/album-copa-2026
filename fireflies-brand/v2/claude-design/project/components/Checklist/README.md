# Checklist

Checklist com progresso: passos numerados (01, 02…) com caixa de marcação; o leitor marca o que já fez e a barra mostra o avanço.

- Cada item: título em `<strong>` e uma frase. Item concluído recebe `ff-feito` (caixa em Folha de Bananeira com ✓ e título riscado).
- No site, o plugin torna os itens clicáveis e guarda o estado no navegador.
