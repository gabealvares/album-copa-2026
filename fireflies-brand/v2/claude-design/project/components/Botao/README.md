# Botao

Botão de ação: o primário (`ff-botao`) leva para a coisa que a página existe para fazer; o contorno (`ff-botao--contorno`) é a segunda opção.

- Use o primário **uma vez por tela**. No claro ele é Anil (`acao`); dentro de `.ff-noite` vira Âmbar, a única luz da composição.
- Texto com verbo no infinitivo ou imperativo, sem ponto final: "Agendar diagnóstico gratuito", "Conversar no WhatsApp", "Fale com nossos especialistas".
- `ff-botao--compacto` só no cabeçalho.
- Consumidor fornece: `<a>` ou `<button>` com a classe, o texto e, opcionalmente, um ícone SVG de 20px antes do texto.
- Não: dois primários lado a lado, botão Âmbar no claro, cantos arredondados além de `raio-controle`.
