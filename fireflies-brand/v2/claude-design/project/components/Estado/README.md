# Estado

Estado: forma + palavra + cor. Ok (círculo com ✓, Folha de Bananeira), atenção (triângulo, Rapadura), crítico (triângulo, Carmim).

- A palavra vem em `<strong>` no começo da frase; nunca comunique estado só pela cor.
- Use estados **só sobre fundo claro** (Branco ou Cal): Folha de Bananeira, Rapadura e Carmim não têm contraste sobre Anil. Dentro de uma página ou seção escura, ponha o bloco de estados numa `ff-superficie-clara`.
