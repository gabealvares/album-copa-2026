# TabelaEditorial

Tabela editorial: fio forte no cabeçalho (Plex Mono caixa alta), fios de 1px entre linhas, sem zebra e sem bordas verticais.

- `ff-tabela--numeros`: colunas de valor em Plex Mono, alinhadas à direita; total em `<tfoot>`.
- `ff-tabela--codigos`: primeira coluna é um código (DARF, subitem).
- `ff-tabela--cartoes`: com 3 colunas ou mais, vira cartões abaixo de 600px. Dê a cada `<td>` o `data-rotulo` da coluna.
- Fonte ou data de referência em `<caption>`.
