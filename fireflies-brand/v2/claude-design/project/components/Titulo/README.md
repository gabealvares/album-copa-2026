# Titulo

Título de página e de seção. `ff-titulo` (H1) em Sora 700 caixa alta; `ff-titulo-2` (H2) em Sora 600 caixa normal.

- Realce **uma palavra** por título com `<span class="ff-realce">` (cor `quente`). Nunca duas.
- Acompanhe com rótulo acima e `ff-abertura` abaixo; feche com `ff-fio-rubrica` quando o título abre uma seção.
- Não recrie o "E de luz" do wordmark em títulos.
