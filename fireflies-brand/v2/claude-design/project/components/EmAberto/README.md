# EmAberto

Em aberto: o que ainda depende de regulamentação ou de decisão. Fundo Âmbar claro, fio e rótulo em Rapadura (`alerta`), com ícone de relógio pontilhado.

- Use **só** para pendências reais (norma não publicada, cenário). Se a regra já existe, use Info.
- Diga o que falta, quem decide e o que acompanhar. Termine o título com o selo do status: "FALTA REGULAMENTAR" ou "CENÁRIO".
