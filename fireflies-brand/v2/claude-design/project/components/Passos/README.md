# Passos

Passos em constelação: etapas em colunas sobre um fio pontilhado Céu; cada etapa é um nó, e a última é a estrela acesa (Âmbar com contorno Anil).

- 3 a 5 etapas. Cada uma: rótulo de prazo, título, frase e o entregável (`ff-entregavel`).
- A estrela Âmbar é a luz da composição: não use outro Âmbar na seção.
