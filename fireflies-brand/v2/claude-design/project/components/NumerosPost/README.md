# NumerosPost

Números do post: os 2 a 4 números que resumem o artigo, sobre Anil, em colunas separadas por fio Céu.

- Cada coluna: rótulo, número (`numero-post`), nome curto e uma frase. O status ("Definido") vai em negrito no fim.
- Vai logo depois da abertura do post, antes do Aviso.
- Consumidor fornece: 2 a 4 itens {rótulo, número, nome, descrição}.
