# BaseLegal

Base legal: as normas que sustentam o texto, com o trecho literal. Fundo Cal, fio Anil no topo, rótulo com fio inferior, normas em Plex Mono.

- Cite o nome completo da norma e o artigo no `<h4>`; transcreva o trecho em `<blockquote>` **literalmente**. Paráfrase vai em Info, nunca aqui.
- Consumidor fornece: rótulo, pares norma + citação.
