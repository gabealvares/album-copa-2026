Tema de blocos (FSE) da Fireflies Consultoria, identidade v2 "Carta do Lume".

== Description ==

Paleta Noite de São João (Anil de Junho, Cal Virgem, Âmbar de Vagalume, Vermelhão de Rubrica),
Sora + IBM Plex Sans + IBM Plex Mono locais (woff2, OFL), padrões de página (hero, serviços,
passos de 30 dias, painel mensal, raio-X, FAQ, chamadas) e padrões editoriais de post.
Estilos de seção "Noite" e "Cal". Sem page builder, sem jQuery.

Recomendado com o plugin Fireflies Core (cursos da Academy, tempo de leitura, WhatsApp,
índice do post, componentes editoriais, schema.org e ícones).
